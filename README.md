# Chandu // Futuristic Developer Portfolio (100% Static)

A futuristic digital agency experience created for **Chandu** — Creative Developer &amp; Web Architect.

## ⚡ Architecture Overview

- **Full Static Architecture**: Zero Node.js runtime, zero npm dependencies, zero build steps, and zero backend required.
- **Data Exclusively in HTML**: All project details, case studies, service specifications, skill matrices, credentials, and contact channels reside directly inside [index.html](file:///d:/PORTFOLIO-1/index.html).
- **JavaScript for Effects & Redirection Only**:
  - [js/main.js](file:///d:/PORTFOLIO-1/js/main.js): Controls custom magnetic cursor, real-time IST clock, scroll progress, category filtering, HTML modal dialog toggling, HTML service & skill tab toggling, audio triggers, and direct WhatsApp / email redirection. Contains ZERO data objects or text arrays.
  - [js/three-scene.js](file:///d:/PORTFOLIO-1/js/three-scene.js): Interactive WebGL 3D Quantum AI Core (gyroscope rings, glowing wireframe icosahedron, luminous floating particles) and 2D canvas constellation background with mouse repulsion.
  - [js/audio.js](file:///d:/PORTFOLIO-1/js/audio.js): Zero-dependency Web Audio API procedural sound synthesizer (hover chirps, click pulses, success fanfares) with mute toggle.
- **Visual Theme**: Deep Obsidian Black (`#050806`) & Refined Forest Emerald (`#10b981`) — Sophisticated, elegant dark aesthetic with zero harsh neon glare.
- **Unskip-able Sequential Presentation**: All 4 services, 3 completed live client case studies, client partnership commitments, and 6 strategic business advantages with a client decision matrix are fully presented directly in the scroll flow with zero hidden tabs or popups.
- **Responsive System**: Custom stylesheet [css/style.css](file:///d:/PORTFOLIO-1/css/style.css) with explicit `@media` queries across all screen breakpoints (`1200px`, `992px`, `768px`, `576px`, `380px`, and `@media (hover: none)` for mobile touch devices).

## 🚀 How to Run

1. **Direct Browser Execution**:
   - Double-click [index.html](file:///d:/PORTFOLIO-1/index.html) or right-click &rarr; "Open with" Chrome / Edge / Firefox / Safari.
2. **Instant Local Server (Optional)**:
   - Python: `python -m http.server 8080` &rarr; open `http://localhost:8080/`
   - VS Code / Antigravity: Open with "Live Server" extension
3. **Deployment**:
   - Push this entire folder directly to **GitHub Pages**, **Cloudflare Pages**, **Vercel**, or **Netlify** — it deploys instantly with zero build configuration!
